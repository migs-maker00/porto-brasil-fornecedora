# Porto Brasil Fornecedora

Site institucional e comercial B2B da **Porto Brasil Fornecedora** (São Sebastião - SP).

## Desenvolvimento

```bash
npm install
npm run dev
```

## Marca / logo

Coloque o logotipo oficial em `public/brand/logo.svg` (ou substitua `logo-mark.svg`) **sem alterar proporções**.
O mark atual em `logo-mark.svg` é provisório até o arquivo oficial ser inserido.
